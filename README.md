# Байкал Север

Адаптивный туристический сайт об экскурсиях и путешествиях по Байкалу. Проект
поддерживает два режима: простое открытие статического `index.html` и полноценный
WordPress с MySQL, Nginx и ACF Pro в Docker.

## Статический запуск

Откройте `index.html` в браузере. Дополнительная сборка не требуется.

Для простого локального HTTP-сервера:

```bash
node dev-server.js
```

После запуска сайт доступен по адресу `http://localhost:4173`.

## WordPress

1. Скопируйте `.env.example` в `.env` и задайте локальные пароли.
2. Поместите ACF Pro в `wordpress/wp-content/plugins/advanced-custom-fields-pro`.
3. Запустите окружение:

```bash
docker compose up -d
```

WordPress доступен по адресу `http://localhost:8080`, административная панель —
`http://localhost:8080/wp-admin/`.

Тема `Байкал Север` находится в `wordpress/wp-content/themes/baikal-sever`.
Основные тексты первого экрана и контакты редактируются в панели
`Байкал Север`, которую добавляет ACF Pro.

## Развёрнутая версия

Рабочий сайт: [http://85.198.85.68/](http://85.198.85.68/)

На сервере проект размещён в `/opt/baikal-sever` и работает в контейнерах
